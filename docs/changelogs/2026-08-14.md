- Resume 핵심 역량의 Markdown 강조·문단 렌더링과 관리자 작성 안내 추가

- Resume 학력 구분선 여백을 경력 메타데이터와 통일하고, 언어 카드를 모바일 1열·tablet 이상 2열로 구성

- Resume 언어 카드의 강조색 왼쪽 테두리 제거
- Resume 관리자에서 직무 분야별 대표 프로젝트 선택·순서 관리 추가
- Resume 대표 프로젝트 카드에 기업·개인 프로젝트 유형 표기 추가
- Portfolio 기업·개인 프로젝트 구획 header와 카드별 유형 표기 보강
- Portfolio 상세 정보·담당 업무·결과 카드 행의 유동 폭 채움 적용
- Portfolio 상세 프로젝트 목표의 제목·설명 카드 분리 및 담당 업무와 섹션 구조 통일
- Landing 핵심 역량의 Markdown 기본 렌더링과 관리자 Markdown 전환 추가
- Landing 핵심 역량 카드의 번호·제목·설명 구조를 Resume 카드와 통일
- Portfolio 상세 프로젝트 목표의 줄바꿈 목록 렌더링과 담당 업무 모바일 1열·tablet 이상 2열 고정 적용
- Portfolio 상세 담당 업무를 단일 카드 안의 다중 목록으로 통일
- Markdown 본문 이미지 캡션과 출처 링크 렌더링 추가
- Markdown 본문 이미지와 캡션의 공통 정렬 속성 추가
- Resume 대표 프로젝트 관리자 E2E 검증 문구 갱신
