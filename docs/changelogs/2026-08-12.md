# Changelog: 2026-08-12

## Carevia JD 근거 보강

- 외주사가 10개월간 진행한 미완성 통행배정 codebase를 마감 2개월 전에 인수해 핵심 로직을 추출하고 FastAPI 서버로 전면 재설계·준공한 경력 사실을 이력서와 Portfolio에 반영
- 기존 Spring Boot 연계 API 서버의 동작·통신 규격을 확인하며 배포한 경험을 `기초` 수준으로 한정하고 Spring Security·JPA·QueryDSL·MySQL 경험은 추가하지 않음
- AI 팀의 실제 파일 업무 순서를 업로드·상태 확인·자동 분류·탐색 흐름으로 설계한 과정을 AI 파일 관리 Portfolio에 보강
- Portare Folium의 공식 WCAG 검수 여부와 읽기 피로·클릭 수를 줄인 UI 판단을 구분해 기술
- WebView·hybrid app·native push·offline sync·WebSocket 구현 여부를 source와 dependencies에서 점검하고 경험 근거가 없음을 확인

## 웹 지원 자료 채용담당자 관점 개선

- 웹 이력서의 프로젝트 8개 card를 Featured 대표 3건의 direct link와 전체 Portfolio 진입으로 압축
- 기술 view selector와 동일 높이 card를 제거하고 category별 가로 행, inline 숙련도, 채워진 fallback badge로 재설계
- Portfolio 이전 기록의 펼치기 toggle을 제거하고 tablet 이상 우측 중앙 고정 목차와 한국어 안내 문구 적용
- Portare Folium에 App Router 구조, 관리자 운영 기능, 실제 editor 화면을 추가하고 주요 실무 Portfolio의 역할·문제 해결·결과 서술 보강
- `Nexon Open API`를 기술 목록에서 제거하고 경력·핵심 역량·게임 profile 데이터는 기존 사실 그대로 보존

## 분야별 공개 경로 E2E 정합성

- Resume, Portfolio, Blog E2E가 분야 선택 화면이 아닌 `/web` 공개 콘텐츠 경로를 검증하도록 갱신
- 인증 setup과 PDF export 검증의 사전 로드 경로를 web profile 계약에 맞게 정리
- navigation E2E의 클릭과 URL 전환 대기를 결합해 hydration 시점의 간헐 실패 방지

## 웹 이력서·포트폴리오 사실 정합성

- 웹 소개와 핵심 역량을 게임 프로필과 독립된 직무 범위로 갱신하고 기존 게임 소개·핵심 역량은 보존
- 웹 이력서 프로젝트를 최신 웹 포트폴리오 7건과 ROI 도구까지 8건으로 정리하고 상세 페이지 연결·역할·결과 보강
- Portare Folium의 Supabase·Cloudflare R2·NextAuth·MCP 등 최신 웹 기술을 기술 섹션에 반영
- 이력서 경력 섹션을 사실 정본으로 유지하고 ITS 처리량, AI 파일 관리 효율, 클라이언트 사이트 성과를 관련 포트폴리오에 반영
