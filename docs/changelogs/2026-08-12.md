# Changelog: 2026-08-12

## 분야별 공개 경로 E2E 정합성

- Resume, Portfolio, Blog E2E가 분야 선택 화면이 아닌 `/web` 공개 콘텐츠 경로를 검증하도록 갱신
- 인증 setup과 PDF export 검증의 사전 로드 경로를 web profile 계약에 맞게 정리
- navigation E2E의 클릭과 URL 전환 대기를 결합해 hydration 시점의 간헐 실패 방지

## 웹 이력서·포트폴리오 사실 정합성

- 웹 소개와 핵심 역량을 게임 프로필과 독립된 직무 범위로 갱신하고 기존 게임 소개·핵심 역량은 보존
- 웹 이력서 프로젝트를 최신 웹 포트폴리오 7건과 ROI 도구까지 8건으로 정리하고 상세 페이지 연결·역할·결과 보강
- Portare Folium의 Supabase·Cloudflare R2·NextAuth·MCP 등 최신 웹 기술을 기술 섹션에 반영
- 이력서 경력 섹션을 사실 정본으로 유지하고 ITS 처리량, AI 파일 관리 효율, 클라이언트 사이트 성과를 관련 포트폴리오에 반영
