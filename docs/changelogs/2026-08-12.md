# Changelog: 2026-08-12

## 직무별 공개 경로와 관리자 반영

- Portfolio·Blog·Resume·About Me 저장 시 `/web`·`/game` 공개 경로까지 cache revalidation하도록 보강
- Published Portfolio 편집본은 Draft로 저장되고 이전 공개본이 유지된다는 상태를 관리자 editor와 저장 결과에 명시
- 인증 Chromium에서 Portfolio editor의 공개 반영 안내와 browser runtime 오류 부재를 검증
- Portfolio는 저장 직후 즉시 Published하며 Draft·검토·승인·발행 workflow와 공개 snapshot 차단을 제거
- Resume 대표 프로젝트 편집 바로가기가 admin scroll container를 즉시 이동하도록 보강

## Resume 대표 프로젝트 편집성과 제목 규칙

- Web Resume의 대표 프로젝트 제목을 공통 label helper로 통합해 emoji가 항상 `🚀 대표 프로젝트`처럼 맨 앞에 표시되도록 수정
- 관리자 Resume 상단에 대표 프로젝트 편집 바로가기를 추가하고 공개 layout에서 disabled인 section도 관리자에서는 계속 편집할 수 있도록 분리
- 대표 프로젝트 선정·순서와 이력서 설명의 관리 위치를 editor 안에 안내하고 인증 E2E로 편집 구역 이동과 browser 오류 부재를 검증
- Resume·Portfolio·About Me·Blog 및 원칙상 Landing page까지 공개 콘텐츠를 Admin Dashboard에서 편집해야 한다는 architecture 계약 추가

## Resume 기술 브랜드 표시

- Resume 기술 keyword에 DB 기반 `iconUrl`을 추가하고 관리자 편집·미리보기·목록에서 같은 logo source를 사용하도록 연결
- Java는 OpenJDK, Cloudflare R2·SQLite3·Synology NAS API·MCP는 Simple Icons의 검증된 slug와 brand color로 지정
- Amazon S3·Zustand·NextAuth는 공식 자산을 Cloudflare R2에 저장하고 Next.js image optimization을 거쳐 화면과 PDF preview에서 같은 logo를 표시
- Resume 직무별 기술 분리, logo 로딩, PDF 생성·다운로드를 자동화 검사로 확인

## Portfolio article media와 목차 경계

- Portfolio 대표 image gallery의 제목을 `대표 이미지`로 통일하고 손상된 Portare Folium 화면을 새 16:9 capture와 lightbox thumbnail로 교체
- 최적화 thumbnail이 없을 때 원본 image로 fallback해 filmstrip 탐색이 깨지지 않도록 보강
- 우측 중앙 고정 목차가 article body 안에서 시작하도록 sticky 범위를 분리해 대표 이미지 영역과의 충돌 제거
- Portare Folium article에 문맥별 image, blockquote, table, code tree, list를 배치하고 작성 guide·관리자 prompt·design directive에 같은 원칙 반영
- 로컬 운영용 `docs/private` script를 product TypeScript build 범위에서 제외

## 웹 공개 자료 읽기 흐름 개선

- 기술 view selector와 동일 높이 card를 제거하고 category별 가로 행, inline 숙련도, 채워진 fallback badge로 재설계
- Portfolio 이전 기록의 펼치기 toggle을 제거하고 tablet 이상 우측 중앙 고정 목차와 한국어 안내 문구 적용

## 분야별 공개 경로 E2E 정합성

- Resume, Portfolio, Blog E2E가 분야 선택 화면이 아닌 `/web` 공개 콘텐츠 경로를 검증하도록 갱신
- 인증 setup과 PDF export 검증의 사전 로드 경로를 web profile 계약에 맞게 정리
- navigation E2E의 클릭과 URL 전환 대기를 결합해 hydration 시점의 간헐 실패 방지
