# 이력서 PDF 생성 공식 (PDF-C / PDF-F)

AI 없이 템플릿과 알고리즘만으로 이력서 PDF를 만든다. 같은 입력이면 같은 PDF가 나온다.

```text
PDF = Verify(Paginate(Render(Order(Select(Merge(Data, lang), field, opts)), lang)))
```

## 변형

| 변형  | 용도                                        | 언어   |
| ----- | ------------------------------------------- | ------ |
| PDF-C | 화면으로 읽는 컬러 이력서                   | ko, ja |
| PDF-F | 일본 기업 제출용 履歴書 + 職務経歴書 (흑백) | ko, ja |

## 단계와 모듈 (`src/lib/resume-pdf/`)

| 단계     | 모듈                                 | 내용                                                                                                                                     |
| -------- | ------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------- |
| Merge    | `source.ts`, `load.ts`               | 언어별 행 조회. 번역 행에는 ko 원본의 구조 값(기간·종류·링크·인원·AI 표시)을 보충. 미공개 행 제외                                        |
| Select   | `options.ts`, `visibility.ts`        | 사이트 설정 + PDF 덮어쓰기 = 유효 설정. 직무 필터는 사이트 함수 그대로. 기본 프로젝트 집합 = 사이트 대표 목록(최대 5) + AI 에이전트 항목 |
| Order    | `model.ts`                           | 회사 프로젝트 → AI 에이전트 → 개인 프로젝트. 지정 순서는 같은 단 안에서만 적용. 같은 회사 연속 근무 묶기                                 |
| Render   | `render.ts`, `style.ts`, `labels.ts` | HTML 템플릿. 양식어만 언어별 표, 글은 DB 원문                                                                                            |
| Paginate | `paginate.ts`, `browser.ts`          | 한 쪽 이하 묶음은 통째 유지. 履歴書는 빈 행과 自己PR 칸으로 쪽을 채움                                                                    |
| Verify   | `verify.ts`                          | V1–V5. 실패 또는 검사 불가 = PDF 미응답                                                                                                  |

## 계산 규칙

- 근속: 달력상 완성 개월 + 남은 날 30일당 1개월. 총 경력 = 회사별 표시값의 합.
- 고용형태가 바뀔 때만 「登用」/"전환". 종료일 없는 학력 = 재학 중, 미래 종료일 = 졸업 예정.
- 직무 소개가 없으면 공통 글로 대체하지 않고 비운 뒤 경고.
- 숨긴 프로젝트는 그것에서 만든 글(AI 언급, 핵심 역량 AI 카드, 職務経歴書 회사 표)에서도 빠진다.

## 맞춤 설정 (`resume_pdf_presets.options`)

```json
{
    "version": 1,
    "sections": { "awards": true },
    "basics": { "birthDate": false },
    "projects": {
        "order": ["slug-a"],
        "hiddenSubsections": {},
        "compactPersonal": false
    },
    "details": { "educationGpa": false, "excludedCore": ["pdf-id"] }
}
```

- 사이트 기본값에서 바꾼 값만 저장한다. 바꾸지 않은 값은 사이트 설정 변경을 따라간다.
- 모르는 키는 보존한다.

## 관문

| 관문 | 실패 조건                                            |
| ---- | ---------------------------------------------------- |
| V1   | 마지막 쪽이 아닌 쪽의 마지막 줄이 제목·머리글뿐      |
| V2   | 한 쪽 이하 묶음의 처음·끝 표식이 같은 쪽에 함께 없음 |
| V3   | 다른 직무 전용 항목의 글자                           |
| V4   | ko 외 언어에 한글                                    |
| V5   | ja에서 ko 이름이 한글인데 이름에 한자                |

V4는 번역의 뜻이 같은지까지 증명하지 못한다.
