# Profile Navigation Guide

## 공유할 링크

| 지원 분야 | Resume         | Portfolio         |
| --------- | -------------- | ----------------- |
| Web       | `/web/resume`  | `/web/portfolio`  |
| Game      | `/game/resume` | `/game/portfolio` |

지원하려는 회사에 맞는 Portfolio URL을 공유한다. Portfolio 카드의 Case Study와 Resume의 프로젝트 링크는 같은 profile URL 안에서 열린다.

기본 `/about`, `/resume`, `/portfolio`, `/blog`는 profile을 선택하는 안내 화면이다. 구체적인 지원 링크로 사용하지 않는다.

## 방문자 이동 방식

- Web 또는 Game 링크로 방문하면 Header의 About me·Resume·Portfolio·Blog와 로고가 현재 profile을 유지
- Portfolio 상단의 Resume도 같은 profile Resume로 이동
- 일반 About·Blog·전역 Resume 링크는 profile 화면에서 숨김
- Header에는 다른 분야로 이동하는 link가 없다. 분야 변경은 기본 경로의 profile 선택 화면에서만 시작

## 확인할 곳

1. `/web/portfolio`에서 web 프로젝트와 기술만 보이는지 확인
2. `/web/resume`에서 web 경력·기술만 보이는지 확인
3. `/game/portfolio`에서 DMC5·Pragmata 등 game 프로젝트가 보이는지 확인
4. `/game/resume`에서 game 경력·기술만 보이는지 확인
5. `/web/blog`, `/game/blog`에서 각 분야 포스트만 보이는지 확인

직무를 바꾸는 데이터 편집은 관리자 Resume 화면에서 경력 단계와 핵심 역량의 job field를 지정해 수행한다. Portfolio 항목은 기존 job field 설정을 사용한다.
